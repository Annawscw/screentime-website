# Teen Screen Addiction — and how to handle it

A website for New Zealanders aged 13–18 that helps them recognise, manage and reduce screen addiction by showing them their own habits and giving them small, specific things to change.

Built by Anna Watt for NCEA Level 3 Digital Technologies (AS 91907), 2026.

**Inquiry question:** How can I develop an application that helps teenagers aged 13–18 recognise, manage and reduce screen addiction by encouraging healthier digital habits and a balanced daily routine?

## Pages

- **Home** — what the site is for, the three steps it takes you through, and the New Zealand numbers that explain why it exists.
- **The Quiz** — ten questions, about ninety seconds. It scores four separate dimensions (loss of control, displacement, mood and withdrawal, conflict) and returns one of four profiles, so you find out *which* part of your phone use is the problem rather than just getting a number.
- **Reality check** — log your real screen hours each day, set a goal you'd actually hit, and watch a fourteen-day chart. It also works out your seven-day average, your current streak, and what those hours cost you over a year.
- **Addiction buster** — sixteen swap cards filtered by the habit you struggle with (sleep, focus, social, boredom), a 25/5 focus timer, a seven-day challenge that saves your progress, and a wind-down plan that rebuilds itself around your bedtime.
- **The Facts** — why stopping is hard, the New Zealand picture, and where the numbers come from.

## How it works

The quiz, the dashboard and the toolkit are all driven by plain JavaScript in `js/`. None of the page content is generated by script: every question, card and challenge day is written in the HTML or in `js/questions.js`, and the scripts only attach behaviour to what is already there.

| File | What it does |
|---|---|
| `js/app.js` | Runs on every page. Sets the dark theme and clears the old light-mode preference. |
| `js/questions.js` | The quiz data — the four dimensions, the ten questions, and the four result profiles. |
| `js/quiz.js` | Runs the quiz: scoring, keyboard navigation, the result screen and the dimension bars. |
| `js/dashboard.js` | The Reality check page: logging, the chart, the averages, export and delete. |
| `js/toolkit.js` | The Addiction buster page: flip cards, filters, the focus timer, the challenge and the wind-down plan. |

## Privacy

Nothing is sent anywhere. There is no account, no login, no server and no analytics. Everything the site remembers is kept in the browser's own `localStorage` on that one device:

| Key | What it holds |
|---|---|
| `quizResult` | Your most recent quiz score and profile |
| `screenLog` | Your daily screen-hour entries |
| `screenGoal` | Your daily hours goal |
| `challenge` | Which of the seven challenge days you have ticked |
| `focus-<date>` | Focus sessions finished today |
| `bedtime` | The bedtime the wind-down plan is built around |

The **Export my data** button on Reality check downloads all of it as JSON, and **Delete everything** removes the lot. Every read and write is wrapped in `try`/`catch`, so the site still works in private browsing where storage is blocked.

## Accessibility

- Skip-to-content link on every page
- Every image has alt text, and headings run in order
- Decorative SVG is `aria-hidden`; the curved cloud headings carry the same words as real text for screen readers
- Interactive elements are real `<button>` and `<a>` elements with `aria-pressed`, `aria-current` and `aria-live` where the state changes
- The quiz can be answered with keys 1–4 and the arrow keys
- Visible focus outlines throughout
- Text colours meet WCAG AA contrast against their backgrounds
- All animation stops for anyone whose system asks for reduced motion (`prefers-reduced-motion`)
- Layout tested from 320px to 1920px wide

## Built with

HTML, CSS and JavaScript, written by hand. No frameworks, no build step and no libraries. The only external request is to Google Fonts for Bricolage Grotesque, Instrument Sans, Fraunces, Rubik Glitch and Space Mono.

The site is dark only. Colours, spacing and type are set once as CSS custom properties at the top of `style.css` and used everywhere else, so one change there updates the whole site.

## Running it

Download or clone the repository and open `index.html` in a browser. There is nothing to install and no server needed.

```
git clone https://github.com/Annawscw/screentime-website.git
```

Once GitHub Pages is turned on for the `main` branch, the live site will be at <https://annawscw.github.io/screentime-website/>.
